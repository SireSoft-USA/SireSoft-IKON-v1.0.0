# SireLLM Frontend Assets

All assets in this folder are project-local, dependency-free SVG files.

The folder contains:

- `sirellm-mark.svg` — primary SireLLM brand mark
- `favicon.svg` — compact browser icon
- `source-document.svg` — retrieval/source UI icon
- `empty-chat.svg` — empty conversation illustration
- `asset_manifest.json` — machine-readable asset inventory

No remote image host, icon library, font service, tracking pixel, CDN, or
embedded script is required.

The SVGs use the same neutral dark + lime interface palette defined by
`frontend/css/app.css`.
